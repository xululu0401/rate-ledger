# 均值拆账

模型调用量、评测成功率、渠道转化率，都可能被汇总成一个醒目的数字。但当样本构成变了，仅看总率，容易把另一件事当成表现变化。均值拆账专门处理两期分组成功率的对照。

填入每组两期的样本数和成功数，工具会计算总成功率，并把变化拆成组内率项与构成项。两项使用对称权重，合计恰好等于总率变化，不留下无法解释的交叉项。

默认是一组虚构演示：简单任务成功率90%变95%，复杂任务20%变35%，每组都提高；但复杂任务的样本占比从50%变90%，总成功率反而由55%降至41%。组内率项+12个百分点，构成项−26个百分点，合计−14个百分点。以上不是任何厂商的实测成绩。

如果固定基期样本构成，改用本期各组成功率，重新加权的本期为65%。页面把这个反事实与实际总率分开，避免把标准化结果当成真实成功人数。

支持2–8组、对换两期、即时改参和分组条形图；可导出CSV明细、Markdown解读、PNG结果卡及JSON备份。无登录、无模型API，数据只在本地处理。默认不保存，主动勾选后才记住数据，取消勾选即清除本工具记录。

两期分组须一致、互斥且覆盖全部样本，“成功”也须使用同一标准。零样本组不能计算成功率，本工具会拒绝处理，不能把它擅自当作0%。分组粒度会影响解释；这只是描述性代数分解，不证明因果，也不做显著性检验。

v1.0.0已完成9项核心测试，含600组随机数据的分解守恒、样本复制与重排检查；浏览器实测保存恢复、错误输入、备份校验、四种导出、8组上限与手机排版。

## 公式

R=Σwr；组内率项E=Σ[(w₀+w₁)/2×(r₁−r₀)]，构成项M=Σ[(r₀+r₁)/2×(w₁−w₀)]；E+M=R₁−R₀。固定基期权重的本期R*=Σw₀r₁。乘100转换为百分点。
